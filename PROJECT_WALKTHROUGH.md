# Project walkthrough

## Problem
Explore which customer characteristics are associated with churn and present the findings clearly.

## Workflow
1. Generate a reproducible customer dataset.
2. Load and inspect it with pandas.
3. Create a binary churn flag.
4. Segment churn by contract, payment method and support status.
5. Compare churned vs retained customers.
6. Visualize the strongest patterns with Matplotlib.

## What to explain in a discussion
- Why exploratory data analysis comes before modeling.
- How groupby is used to calculate segmented churn rates.
- Why month-to-month customers can be compared with annual-contract customers.
- Difference between an association and a causal explanation.
- What additional data you would want before recommending a retention action.

## Limitation
The dataset is synthetic and the project is descriptive EDA, not a predictive churn model.
